# Hybrid Intelligence Architecture

This project features a robust **Hybrid Intelligence Fallback** system designed to ensure 100% uptime for the AI Analysis module, even when external LLM APIs are unavailable (e.g., rate limits, invalid keys, or $0.00 balances).

## How It Works

1. **API Integration (`src/llm_insights.py`)**
   - The application attempts to connect to the Anthropic API (Claude 3.5 Sonnet) to generate advanced, unstructured market analysis.
   - The connection is wrapped in a strict `try/except` block targeting `anthropic.AuthenticationError` and `anthropic.RateLimitError`.

2. **Local Fallback (`get_heuristic_analysis`)**
   - If the API call fails due to account limits, the system catches the exception and immediately defaults to the local heuristic engine.
   - It parses the pre-calculated KPI dictionary (Sharpe Ratio, Volatility, Total Return) generated by `src/processing.py`.
   - It generates a deterministic, structured Markdown report featuring:
     - **Market Trend:** Bullish or bearish sentiment based on trailing returns.
     - **Risk Assessment:** Analyzes the Sharpe ratio and annualized volatility thresholds to provide a comprehensive risk summary.

3. **Graceful UI Handling (`app.py`)**
   - The UI natively detects when the fallback has been triggered (`is_fallback = True`).
   - Instead of displaying a raw Python stack trace or a generic "API Error", the dashboard gracefully renders the local report accompanied by a yellow warning badge: `st.warning("⚠️ Using Local Heuristic Engine (API Limit Reached)")`.
   - Furthermore, the dashboard leverages Streamlit's innate execution model where button states (`st.button`) reset to `False` upon a page reload (`st.rerun()`). This guarantees that the background "Auto-refresh (30s)" feature only updates price data, never triggering redundant, costly API analysis cycles.

This system guarantees a seamless, professional User Experience regardless of external API state.
